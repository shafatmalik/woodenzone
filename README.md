# Woodenzone Website

Homepage for **Woodenzone**, a wooden furniture, lighting, home décor and kitchenware maker in Saharanpur, India.

*Crafted by Nature, Made for You.*

## Files
- `index.html` – the whole site (HTML, CSS and JavaScript in one file)
- `images/` – product photos, `img-01.jpg` to `img-50.jpg`
- `PROMPT.md` – the prompt used to design and build the site

## Run it
Keep `index.html` and the `images/` folder together and open `index.html` in a browser. No build step.

## Host it free
In the repository go to **Settings → Pages**, choose the `main` branch and the root folder, then save.

## Products
Products are one array in `index.html`: `[name, sku, description, category, imageIndex]`. `imageIndex` 0 is `img-01.jpg`.
